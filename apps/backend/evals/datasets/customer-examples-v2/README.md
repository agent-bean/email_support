# Current customer examples review guide

This is a refreshed version of the six owner-provided situations, each in English and Vietnamese. It updates the synthetic sender-supplied websites for Viettel Solutions and Bosch Global Software Technologies Vietnam using the sources in [website-verification.md](website-verification.md). The original screenshot-derived inputs and historical run bindings remain in [`customer-examples-v1`](../customer-examples-v1/README.md).

These emails and sender addresses are synthetic. The website in an email is still an input claim, not proof of the sender's identity or a source snapshot for a briefing. All expectations remain candidates awaiting owner review. No company facts, calendar events or attachment contents were invented; the Viettel attachment mentioned in the screenshot was not provided.

Replay scores relevance only; the rubric supplies bilingual review criteria. Identity, research and briefing quality and workflow effects are not established by this interpretation-only dataset. Sources in the verification note confirm the selected website addresses; `sources.json` remains empty because these are not versioned research snapshots and do not establish claim support.
