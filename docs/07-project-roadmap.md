# Implementation roadmap

Delivery belongs to the [v1.0.0 milestone](https://github.com/agent-bean/email_support/milestone/1), tracked by the [release issue](https://github.com/agent-bean/email_support/issues/21). The [GitHub Project](https://github.com/orgs/agent-bean/projects/15) owns status and priority. Issues own scope and acceptance criteria; native sub-issues express scope grouping and dependency links express delivery order.

Deliver incrementally within the release:

- Establish typed applications, canonical persistence, durable jobs, and owner access.
- Connect Gmail and Calendar, classify and resolve company context, then add bounded research and approved-knowledge retrieval.
- Complete resumable briefing, exact review/approval, safe delivery, and observability.
- Add PDF/Word export and supported attachment ingestion, then verify the integrated release and deployment path.
